# Wio Tracker L2 product image

Use Seeed's [front product photo][front] for the base L2. The [model comparison][models] identifies which assembly is pictured. With the text upright, the screen is landscape. The black rectangular bezel covers most of the front. Narrow strips of the dark board and rows of holes are visible above and below it. The amber display flex is visible on the right edge.

For a project cover, preserve those exposed edges and the orientation of the flex. The photo shows the Meshtastic status screen. Screen contents can vary with the firmware. Use the [device layout](../AGENTS.md#physical-layout) for the annotated component-side and enclosure views. Preserve the right-hand control order when drawing the assembled unit from the front.
